## Compatibility constraints

V1 fields/prefixes, V2 gating, both delta algorithms, per-socket base/sequence, tag filtering, byte refunds and close semantics remain explicit regression targets. AI rollup remains egress-only: every original mutation still reaches persistence/history/recovery/webhooks/push before rollup. Kafka generation changes require paused publishers, a recorded/drained old-generation watermark on every node, and coordinated rollout; rollback repeats the drain in reverse. No production migration or topic deletion has run.
